# RC Circuit Capacitor Charging Simulation

## Project Overview
This project simulates the charging behaviour of a capacitor in a series RC circuit using MATLAB.

## Objective
To understand how capacitor voltage changes over time when connected to a DC voltage source.

## Circuit Parameters
- Supply Voltage: 5 V
- Resistance: 1000 Ohms
- Capacitance: 100 microfarads
- Time Constant: 0.1 seconds

## Mathematical Theory

Vc(t) = Vs(1 - exp(-t/RC))

Time Constant:

τ = RC = 0.1 seconds

## Software Used
- MATLAB

## Results
The simulation demonstrates the exponential increase of capacitor voltage over time, approaching the 5 V supply voltage.

## Learning Outcomes
- Understanding RC circuit charging.
- Calculating the time constant.
- Implementing equations in MATLAB.
- Generating engineering graphs.
